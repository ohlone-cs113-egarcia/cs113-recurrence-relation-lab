# cs113-recurrence-relation-lab

Last class we implimented recurrence relations using for loops. For this lab redo what we did last class which was implimenting arithmetic sequences, factorials, and the collatz sequence with recursion.

1. arithmetic-recursive.cpp should have a function of the form int add_rec(int a, int d, int n) where a is the starting value, d is the common difference, n is the number of terms the function returns. Out for add_rec(3, 2, 4) should be 3 5 7 9.
2. factorial-recursive.cpp should have a function of the form int fac_rec(int n). Output for for fac_rec(5) should be 120.
